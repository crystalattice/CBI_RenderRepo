# RenderRepo inside Comfy

**[Start here: install and use RenderRepo](../../docs/START_HERE.md).**

The user guide covers importing/installing packages, browsing repositories, using
local files, managing downloads, exporting, updates/removal and troubleshooting.
It is the canonical user walkthrough for the current interface.

This directory contains the Comfy entry point and frontend. Installing the RR
Python package alone does not install this extension directory. Follow the
[user setup steps](../../docs/START_HERE.md#1-install-renderrepo) for both parts.

For maintainers: [extension integration, state and tests](../../docs/DEVELOPMENT.md).
For terminal use: [CLI reference](../../docs/CLI_REFERENCE.md).
For formats: [package/index contract](../../docs/PACKAGE_V0.md).
The sanitized [demo evidence summary](../../docs/DEMO_EVIDENCE.md) distinguishes graph facts, local reuse and untested execution.
